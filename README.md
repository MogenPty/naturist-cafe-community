# Naturist Cafe Community Website

A modern, single-page website for the Naturist Cafe Community association in South Africa, built with Vite, React, and custom CSS styling.

## 🌟 Features

- **Single-Page Application**: Smooth scrolling navigation between sections
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern Aesthetic**: Clean, minimalist design with nature-inspired color palette
- **Interactive Components**: Hover effects, animations, and smooth transitions
- **Placeholder Integration**: Ready for future PDF viewer and calendar components

## 🏗️ Technology Stack

- **Frontend Framework**: Vite with React (TypeScript)
- **Styling**: Custom CSS with CSS Variables
- **Fonts**: Inter (body text) and Playfair Display (headings)
- **Icons**: Inline SVG icons
- **Build Tool**: Vite for fast development and optimized builds

## 📱 Website Structure

### Navigation
Fixed header with smooth scroll navigation to all sections:
- Home, Constitution, Markets & Walks, Board, Join, Login

### Sections

1. **Hero/Home Section** - Welcome message and call-to-action
2. **Constitution Section** - PDF viewer placeholder and download
3. **Markets & Walks Section** - Calendar placeholder with "Coming Soon"
4. **Board Section** - Member profiles and community information
5. **Join Section** - Membership benefits and contact information
6. **Login Section** - Member login with exclusive content preview

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd c:\Projects\ncc
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser to `http://localhost:5173`

### Build for Production

```bash
npm run build
```
